# Baia-School-Hub
This is a website for the Baia community. It will help everyone interact and get the help and necessary attention they deserve, even clubs.
------------- ------------- -------------------------- ------------- ------------- ------------- ------------- -------------
This project was created with the intention of making an interactive school community and learning about what schools are about, what clubs offer, the specific activities they have, and what you can learn from them.

The first log on this project was a futile attempt to make a school hub. 
The programs you will be able to have and use are calculators, GPA calculators, an interactive community where you will see club activities, school events and even the public school calendar. Religious Calendars will be added later on.

When making this project, please name yourself, say you've edited, and don't use this project in an attempt to make a dark school hub. I don't use onion, and you're not a government official to use onion.

When handling this project pls name the original owner of this project. 

Make sure to promote a good environment.
